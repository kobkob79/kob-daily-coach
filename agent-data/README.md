# Viora agent data

This directory contains generated, read-only snapshots used to transport safe Viora data to ChatGPT agents through GitHub.

`exercise-registry.snapshot.json` is generated from the live Viora Exercise Registry. Do not edit it manually. The live Registry remains the source of truth; this snapshot is only a transport artifact.

Future generated snapshots may be added here without changing this convention, such as advisor, coach-media, design-system, or nutrition snapshots.
